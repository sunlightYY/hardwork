# 角色贴图规格

场景背景用的是 `assets/art/room.png`（由参考插画缩放到 1280×720），
地板线固定在屏幕 **y = 600**。角色按 1:1 直接绘制，不要再靠引擎放大。

## 画布与网格

| 项目 | 数值 |
|---|---|
| 单帧画布 | **320 × 320**（透明背景） |
| 网格 | 3 列 × 5 行 |
| 成品尺寸 | **960 × 1600** PNG |
| 行顺序 | 1 正面 down / 2 背面 up / 3 朝左 left / 4 朝右 right / 5 坐姿 sit |
| 列顺序 | 1 待机 / 2 迈步 A / 3 迈步 B |

如果只想画左右两个方向，可以只出 3 行（left / right / sit），告诉我我改加载器。

## 格内对位（关键）

```
(0,0) ┌─────────────── 320 ───────────────┐
      │                                     │
      │           头顶 ≈ y 10               │
      │              ●                      │
      │         肩宽 ≈ 110                   │
      │           ┌───┐                     │
      │           │   │                     │
      │           └───┘                     │
      │         两脚间距 ≈ 50                │
      │        ▲                            │
      │       脚底 y = 310  ← 引擎按这条线对齐地板
      └─────────────────────────────────────┘
                     x 居中 160
```

- **脚底固定在 y = 310**，所有帧都必须一致，否则走路会上下跳。
- 水平居中在 x = 160，左右对称。
- 头顶大约 y = 10，即人物高度约 **300px**（地板到头顶 300px，对应的层高约 445px）。
- 待机帧两只脚都在 310；两个迈步帧前后脚差 12–20px。

## 坐姿帧（第 5 行）

只画到腰部以上，下半身会被投影到桌面之后：
头部在格子中上部（低头，头发占大部分），肩到 y ≈ 250 截止。

| 部位 | 建议色 |
|---|---|
| 衬衫 | `#f5f7fa` |
| 西裤 | `#23262d` |
| 皮鞋 | `#15171c` |
| 头发 | `#1b1d22` |
| 皮肤 | `#f0c9a6` |
| 主管西装 | `#1c1f26`，领带 `#96262e` |

背景图偏冷紫灰，角色稍微偏暖会更容易从画面里跳出来。
