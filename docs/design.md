# hardwork — 游戏设计文档

GitHub Game Off 2026 · 主题 **SHIFT**
状态：单层原型可玩（2026-11-16）· 当前目标：补齐美术与手感

---

## 一句话

一个 28 层写字楼里的普通职员，靠手表在两个空间之间切换，压抑自己的怨气，躲避主管与怪物，然后逃出这栋楼。

---

## 核心体验

在「必须表现得正常」和「必须做点不正常的事才能活下来」之间来回换档。
恐惧有两个来源：黑夜空间里的怪物，和白天空间里盯着你的领导。
而真正决定难度的，是整栋楼攒下来的**怨气**——它既是你的燃料，也是你的敌人。

---

## 世界观与规则

- 主角在一栋 **28 层**的大厦上班，身份是普通职员。
- 手上的**手表**有一个按钮：按一下，切换空间。
- 切换到另一个空间（下称**黑夜空间**）后：
  - 同事和周围所有人都消失；
  - 楼层里出现**怪物**；
  - 灯光颜色改变，颜色由**怨气浓度**决定（见下节）。
- 目标：利用空间切换**逃出这栋楼**。

### 两个空间的对照

| | 白天空间 | 黑夜空间 |
|---|---|---|
| 人 | 同事、主管、领导都在 | 空无一人 |
| 危险 | 被人看见（社会性死亡） | 怪物（生理性死亡） |
| 灯光 | 普通日光灯 | 浅蓝 / 粉 / 绿 → 深色 → 全黑 |
| 能做什么 | 完成工作、开会、舒缓疲劳 | 穿过白天走不通的路线、躲避追查 |

> 机制上的核心张力：**工作在白天空间才能推进，逃跑路线只在黑夜空间成立。**
> 想逃走就得切换；切走了，工作就停摆。

---

## 怨气系统（核心）

### 来源

- 切换空间的来源是**整个公司员工的怨气**。
- 初期只有主角自己的怨气——由他自己的**工作疲倦**构成。
- 随着游戏推进，公司的、别人的怨气不断汇入，颜色由**浅色系逐渐转深，最终变成黑色**。

### 颜色阶梯

| 怨气浓度 | 灯光 | 怪物 |
|---|---|---|
| 低 | 浅蓝 / 浅粉 / 浅绿 | 无或极少 |
| 中 | 蓝 / 粉 / 绿（饱和） | 少量，局部分布 |
| 高 | 深蓝 / 深紫 / 暗红 | 多，开始主动追逐 |
| 极高 | **黑** | 密集，几乎无法穿行 |

颜色是玩家唯一需要读的「世界状态条」——不需要 UI 数字，看一眼灯就知道现在有多糟。

**数值不可见**：前期玩家完全看不到怨气数值，只能靠灯色判断。只有当怨气越过阈值（当前 0.55）后，
手表才开始显示百分比——「YOUR WATCH IS SHOWING NUMBERS」。这一瞬间本身是一个叙事点：
不是玩家获得了工具，而是他在那之后才被允许看清自己的处境。

### 涨怨气

- 未完成的工作量（工作压力）
- 被领导训斥、被主管盘问
- 在大楼里待的时间越久

### 降怨气（舒缓疲劳）

| 方式 | 备注 |
|---|---|
| 运动 | 3 楼健身运动空间 |
| 玩游戏 | 待定：工位电脑 / 休息区 |
| 完成工作 | 干完活本身就是释放，和「工作量上涨」形成对冲 |
| 穿拖鞋 | 慢，但脚舒服——牺牲速度换稳定 |
| 去厕所洗脸 | 短时、可重复的应急手段 |

> 设计意图：难度不是靠开新关卡给的，是玩家自己一点点攒出来的。
> 舒缓手段要付出时间或速度的代价，所以「压制怨气」和「逃出去」天然抢时间。

### 暂定规则

- 单局内怨气可涨可落，但整体趋势向下沉：舒缓手段有冷却或递减收益，越到后期越难拉回来。
- 怨气是全局值，不是每层独立。

## 主角

- 外观：白色衬衫、黑色西裤、黑色皮鞋、**西瓜头**。
- 镜头距离较远、细节不多，靠轮廓和配色识别。
- 工位下放着一双**拖鞋**。
- **3 楼健身运动空间**存着一双**运动鞋**。

### 服装与移动速度

移动速度按服装计算。

| 服装 | 速度 | 附带效果 |
|---|---|---|
| 拖鞋 | 慢 | 舒缓疲劳，脚步声小 |
| 皮鞋（正装） | 中 | 默认状态 |
| 运动鞋 | 快 | 3 楼健身房获取，脚步声小 |

> 预期形成一条早期目标线：**先拿到运动鞋**——它同时解决速度和噪音。

---

## 场景与角色

- 周围是普通的开放式工位，同事着装与主角接近（白衬衫 + 黑裤）。
- **主管**：整身西装 + 皮鞋，是主要的「追查」压力来源。
- **每层一位高层领导**：如果看到某个人一直在来回走动，会过来训斥，并**增加工作量**。
- 每层的布局由工位、走廊、转角组成；3 楼有健身运动空间，厕所每层都有。

---

## 操作

| 输入 | 行为 |
|---|---|
| 方向键 / WASD | 选定方向后**持续自动前进**，直到被阻挡、换向或停下 |
| Shift | 切换空间（白天 ⇄ 黑夜） |
| 蹲下键 | 蹲下（同时停止前进，暂定） |
| 起立键 | 起立，恢复自动前进 |

自动前进是刻意的：玩家管的是**方向**，速度由服装决定，手感接近推一辆购物车而不是操控一个人。这和无人机镜头的视角是对齐的。

---

## 镜头

- 视角相当于**楼外一架无人机**，跟随主角移动。
- 在碰到转角时，做一次**类 3D 的视角转换**（斜视角/透视切换），然后重新切回平面视角。
- 目的：让横平竖直的楼层平面不显得死板，也让「转角」成为一个天然的节奏点。

---

## 核心循环（单层 MVP）

0. **开场**：主角坐在工位前低头放空，日复一日。手表按钮在此时自行触发，整个世界闪入黑夜空间一次
   （同事消失、灯变蓝），再切回来。随后才提示玩家可以左右移动。
1. 在工位完成固定的日常工作量（内容每天固定，需要**同事配合**）。
2. 怨气在攒，灯色在变深，怪物在变多。
3. 手表按钮 / Shift 切入黑夜空间，穿过怪物把守的区域。
4. 听见主管巡视的动静 → 切回白天空间，装成在正常工作。
5. 被领导看到长时间走动 → 被训斥、工作量上涨 → 怨气更快上涨。
6. 到点被要求去指定楼层**参加会议**。
7. 找机会舒缓疲劳（洗脸、拖鞋、运动）把颜色压回去。
8. 工作完成 → **黑屏动画 `working done`**，进入下一段。
9. 循环收紧，直到找到离开这栋楼的路线。

## 系统拆解

### 主管（追查）
- 巡逻路线 + 视线判定。
- 被看到切换空间 / 长时间走动 → 触发盘问或训斥。

### 高层领导（巡视）
- 每层一个。
- 判定条件：某人「一直在走动」。
- 结果：训斥 → **工作量 +N**。工作量上涨会挤压逃跑时间，也会推高怨气。

### 工作与协作
- 每天的工作内容是固定的。
- 需要同事配合完成 → 必须身处白天空间、且同事在场。
- 未完成时是压力源，完成后是释放源——这是怨气的主要调节阀。
- 完成时播黑屏动画 `working done`（可复用为分段/存档点）。

### 会议
- 到点被要求去某个楼层参加会议。
- 迟到 / 缺席的后果待定（预计：工作量上涨或主管介入）。
- 会议本身是一个强制位移点：**想让玩家在此时做取舍——去开会，还是继续逃。**

### 怪物
- 只存在于黑夜空间，按楼层分布。
- 数量随怨气浓度上升，高浓度时转为主动追逐。
- 具体行为待定（追逐 / 巡逻 / 对光色反应）。

## 当前实现范围（第一版）

**只做一层。** 不做 28 层、不做楼层切换。

必须有的：

1. 一层的平面布局：工位、走廊、至少一个转角。
2. 主角自动前进 + 换向 + 蹲下/起立，像素风外观（白衬衫、黑裤、黑皮鞋、西瓜头）。
3. **Shift 切换空间**：灯光变色、同事消失、怪物出现。
4. **怨气值驱动灯色**，并在数值跨档时改变怪物数量。
5. 一个人形怪物 + 基础追逐。
6. 主管巡逻 + 视线判定 + 训斥反馈。
7. 完成固定工作量 → 黑屏 `working done`；至少一种舒缓手段（建议：厕所洗脸）。

先不做：多楼层、运动鞋与速度差异、会议系统、高层领导巡视的完整逻辑。

## 技术备注（Godot 4.7）

- 兼容性渲染器（`gl_compatibility`），为 WebGL 导出准备。
- 画布拉伸 `canvas_items`，基准分辨率 1280×720。
- 两个空间用**同一套场景 + 分层**实现：白天层/黑夜层各一套节点，Shift 切换可见性，避免维护两份关卡。
- 怨气做成 autoload 里的一个 `float`（0–1），灯色和怪物数量都从它派生：
  - 灯色 = 调色板在两个颜色之间 lerp，不要写死四套贴图；
  - 怪物数量 = 按阈值查表，不做连续插值，避免玩家读不出状态。
- 主角用 `CharacterBody2D`；蹲下改为碰撞盒与速度参数，而不是换一套动画状态机。
- 自动前进：方向向量常驻，`_physics_process` 里持续 `move_and_slide`，被阻挡时不动而不是弹回。
- 转角伪 3D 用独立的镜头脚本实现（`scripts/drone_camera.gd`）：玩家转向超过 60° 时，镜头带一点惯性
  甩到 12° 并轻微拉远、压扁，0.7 秒内回正；关卡下方铺了一层「楼外」暗色底板，所以转出去看到的是
  建筑外部而不是空洞。不碰核心玩法。

## 待定问题

1. 怨气是「全公司共享」还是「主角个人」？现在的写法是两者叠加，但需要一个明确的数值模型。
2. 舒缓手段的递减收益怎么算？冷却？还是每次效果打折？
3. 怪物会不会随着怨气变深而改变行为，而不只是数量？
4. 自动前进下，玩家如何「停下」？蹲下即停是否足够？
5. 拖鞋「舒缓疲劳」与「速度慢」的取舍，玩家能感知到吗，还是只是个陷阱选项？
6. 游戏/娱乐设施放在哪？工位电脑会引来主管视线吗？
7. 白天被人看见「凭空消失」会发生什么？这是不是另一种危险来源？
8. 28 层是真实关卡数量，还是用少数几个代表性楼层滚动拼接？
