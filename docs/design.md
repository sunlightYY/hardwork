# hardwork — 游戏设计文档

GitHub Game Off 2026 · 主题 **SHIFT**
状态：脑暴阶段（2026-11-16）· 当前目标：单层可玩 MVP

---

## 一句话

一个 28 层写字楼里的普通职员，靠手表在两个空间之间切换，躲避主管与怪物，按时开会，然后逃出这栋楼。

---

## 核心体验

在「必须表现得正常」和「必须做点不正常的事才能活下来」之间来回换档。
恐惧来自两处：黑夜空间里的怪物，和白天空间里盯着你的领导和同事。

---

## 世界观与规则

- 主角在一栋 **28 层**的大厦上班，身份是普通职员。
- 手上的**手表**有一个按钮：按一下，切换空间。
- 切换到另一个空间（下称**黑夜空间**）后：
  - 同事和周围所有人都消失；
  - 楼层里出现**怪物**；
  - 灯光颜色改变：紫色 / 粉色 / 蓝色 / 绿色。这些颜色指代**灯光与太阳的颜色**。
- 目标：利用空间切换**逃出这栋楼**。

### 两个空间的对照

| | 白天空间 | 黑夜空间 |
|---|---|---|
| 人 | 同事、主管、领导都在 | 空无一人 |
| 危险 | 被人看见（社会性死亡） | 怪物（生理性死亡） |
| 灯光 | 普通日光灯 | 紫 / 粉 / 蓝 / 绿 |
| 能做什么 | 完成工作、开会、和同事配合 | 穿过白天走不通的路线、躲避追查 |

> 机制上的核心张力：**工作在白天空间才能推进，逃跑路线只在黑夜空间成立。**
> 想逃走就得切换；切走了，工作就停摆。

---

## 主角

- 外观：白色衬衫、黑色西裤、黑色皮鞋、**西瓜头**。
- 镜头距离较远、细节不多，靠轮廓和配色识别。
- 工位下放着一双**拖鞋**。
- **3 楼健身运动空间**存着一双**运动鞋**。

### 鞋子（含义待确认，暂定）

- 拖鞋：慢、脚步声明显 → 容易被发现。
- 皮鞋：默认状态。
- 运动鞋：跑得快、脚步轻 → 但要先想办法到 3 楼健身房拿到。
- 预期形成一条早期目标线：**先拿到运动鞋，再谈逃跑。**

---

## 场景与角色

- 周围是普通的开放式工位，同事着装与主角接近（白衬衫 + 黑裤）。
- **主管**：整身西装 + 皮鞋，是主要的「追查」压力来源。
- **每层一位高层领导**：如果看到某个人一直在来回走动，会过来训斥，并**增加工作量**。
- 每层的布局由工位、走廊、转角组成。

---

## 操作

| 输入 | 行为 |
|---|---|
| 方向键 / WASD | 控制前进方向 |
| **Shift** | 切换空间（白天 ⇄ 黑夜） |
| 蹲下键 | 蹲下 |
| 起立键 | 起立 |

> 蹲下的用途待定：预计关联「避开工位视线」「压低脚步声」「钻进矮通道」。

---

## 镜头

- 视角相当于**楼外一架无人机**，跟随主角移动。
- 在碰到转角时，做一次**类 3D 的视角转换**（斜视角/透视切换），然后重新切回平面视角。
- 目的：让横平竖直的楼层平面不显得死板，也让「转角」成为一个天然的节奏点。

---

## 核心循环（单层 MVP）

1. 在工位完成固定的日常工作量（内容每天固定，需要**同事配合**）。
2. 手表按钮 / Shift 切入黑夜空间，穿过怪物把守的区域。
3. 听见主管巡视的动静 → 切回白天空间，装成在正常工作。
4. 被领导看到长时间走动 → 被训斥、工作量上涨。
5. 到点被要求去指定楼层**参加会议**。
6. 工作完成 → **黑屏动画 `working done`**，进入下一段。
7. 循环收紧，直到找到离开这栋楼的路线。

---

## 系统拆解

### 主管（追查）
- 巡逻路线 + 视线判定。
- 被看到切换空间 / 长时间走动 → 触发盘问或训斥。

### 高层领导（巡视）
- 每层一个。
- 判定条件：某人「一直在走动」。
- 结果：训斥 → **工作量 +N**。工作量上涨会挤压逃跑时间。

### 工作与协作
- 每天的工作内容是固定的。
- 需要同事配合完成 → 必须身处白天空间、且同事在场。
- 完成时播黑屏动画 `working done`（可复用为分段/存档点）。

### 会议
- 到点被要求去某个楼层参加会议。
- 迟到 / 缺席的后果待定（预计：工作量上涨或主管介入）。
- 会议本身是一个强制位移点：**想让玩家在此时做取舍——去开会，还是继续逃。**

### 怪物
- 只存在于黑夜空间，按楼层分布。
- 行为待定（追逐 / 巡逻 / 对光色反应）。

### 灯光颜色
- 紫 / 粉 / 蓝 / 绿，对应灯光与太阳的颜色。
- 用途待定，候选：标识该层怪物类型、标识安全时段、标识空间稳定性。

## 当前实现范围（第一版）

**只做一层。** 不做 28 层、不做楼层切换。

必须有的：

1. 一层的平面布局：工位、走廊、至少一个转角。
2. 主角移动 + 蹲下/起立，像素风外观（白衬衫、黑裤、黑皮鞋、西瓜头）。
3. **Shift 切换空间**：灯光变色、同事消失、怪物出现。
4. 一个人形怪物 + 基础追逐。
5. 主管巡逻 + 视线判定 + 训斥反馈。
6. 完成固定工作量 → 黑屏 `working done`。
7. 无人机式跟随镜头（先不做转角伪 3D）。

先不做：多楼层、运动鞋、会议系统、高层领导巡视的完整逻辑、颜色语义。

## 技术备注（Godot 4.7）

- 兼容性渲染器（`gl_compatibility`），为 WebGL 导出准备。
- 画布拉伸 `canvas_items`，基准分辨率 1280×720。
- 两个空间用**同一套场景 + 分层**实现：白天层/黑夜层各一套节点，Shift 切换可见性，避免维护两份关卡。
- 主角用 `CharacterBody2D`；蹲下改为碰撞盒与速度参数，而不是换一套动画状态机。
- 转角伪 3D 后续用一个独立的「镜头脚本时刻」实现，不碰核心玩法。

## 待定问题

1. 灯光颜色到底代表什么？玩家能读出的规则是什么？
2. 怪物是追逐型还是巡逻型？会不会因为玩家「切换空间」而换位？
3. 拖鞋/皮鞋/运动鞋的差异具体是速度、噪音，还是两者都有？
4. 蹲下除了避视线，是否用于通过矮通道？
5. 会议迟到是扣时间、加工作量，还是直接失败？
6. 白天被同事/领导看见「凭空消失」会发生什么？这是不是另一种危险来源？
7. 28 层是真实关卡数量，还是用少数几个代表性楼层滚动拼接？
